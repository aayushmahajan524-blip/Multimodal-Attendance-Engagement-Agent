# SmartAttend AI — Attendance & Engagement Agent

A beginner-friendly classroom attendance dashboard built with HTML, CSS and JavaScript.

## Features
- Add and remove students
- Mark students Present, Absent, Late or Unmarked
- Select a date and retain attendance per date in browser `localStorage`
- Live statistics and attendance-rate visualization
- Search and filter the class list
- Export the selected date as CSV
- Transparent rule-based attendance summary with supportive follow-up suggestions
- Responsive layout for desktop and mobile

## Run it
1. Extract the ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. Add students, mark attendance, generate the summary, and test CSV export.

No build step is required.

## Honest AI statement
The included report is **rule-based**, not a real generative-AI response. The app intentionally labels this in the UI. It does not use facial recognition, emotion recognition, or infer student engagement from attendance.

If your assignment requires actual Generative AI, connect the report button to an approved AI model through a **server-side backend**. Never place an API key in `script.js` or any browser code. A safe integration pattern is:
1. Browser sends only the necessary attendance counts and anonymized context to your own backend endpoint, e.g. `POST /api/insights`.
2. The backend reads the API key from an environment variable.
3. The backend asks the model to produce a short, supportive summary and returns the text to the browser.
4. The UI clearly indicates when a report was generated by a model versus by local rules.

Use only student information you have permission to process. Prefer aggregate counts over names. Follow your institution's privacy rules and the assignment's AI/API requirements. Do not present the current rule-based report as AI-generated.

## Suggested submission description
**SmartAttend AI** is a responsive classroom attendance and analytics prototype. It allows a teacher to manage a class register, record daily attendance, review class-level statistics, export records as CSV, and generate transparent rule-based summaries with suggested follow-up actions. The current version runs entirely in the browser and saves data locally. Its report feature is a rule-based demo, with a documented pathway for adding a genuine generative-AI model through a secure backend.

## Limitations
- Data is stored in the current browser only; it is not a multi-user cloud database.
- Clearing browser storage can remove saved data. Export CSV backups when needed.
- The demo report uses rules; it does not call an AI model.
- Attendance is not a valid standalone measure of student engagement or learning.
